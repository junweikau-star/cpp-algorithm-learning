# Priority Queue 與 Dijkstra 學習反思



## 學習前後的改變



學習以前，我完全沒有聽過 `priority_queue`。對 Dijkstra 只知道它可以用來處理有權圖，但不知道實際運作方式。



學習後，我理解到 C++ 的 `priority_queue` 預設可以優先取出最大值，也可以使用 `greater` 改成最小堆。Dijkstra 會利用最小堆，每次優先處理目前距離最小的狀態，適合處理邊權重皆為非負數的圖。



## BFS 與 Dijkstra 的差異



BFS 找到的是經過邊數最少的路徑。當每條邊的成本相同時，邊數最少就是總成本最小。



但在有權圖中，經過較少的邊不一定花費較少，因此需要 Dijkstra 比較每條路線的累積成本。



## 最常遇到的問題



我很容易把數字的型別與狀態設定搞混。



例如距離與邊權重需要使用 `long long`，但我曾在中間計算時又使用 `int`，使前面使用 `long long` 失去作用。



在通行券問題中，我也曾把 `dist` 的第二維設成邊數，但它實際上只代表通行券「未使用」和「已使用」兩種狀態。另外，起點狀態也必須正確初始化。



這些錯誤讓我學到，寫演算法前除了理解大致流程，也要逐一確認每個變數的型別、每個維度的意義與初始值。



## Priority Queue 的過期資料



當 Dijkstra 找到更短的距離時，會把新狀態放入 priority queue，但舊狀態不會自動消失。



因此取出狀態時，要將取出的距離和目前記錄的最小距離比較。若取出的距離較大，就代表這是過期資料，應直接跳過。
