BFS 自主學習專題



專題介紹

&#x09;

&#x09;本專題為「圖論 × 動態規劃」自主學習的一部分，以 C++ 作為主要實作語言。第一階段選擇 BFS（Breadth-First Search）作為圖論入門，希望不只是記住演算法模板，而是理解資料結	構、搜尋原理、時間複雜度及實際應用，並透過不同難度的題目驗證學習成果。



學習方式



&#x09;本專題所有程式皆自行撰寫，並要求 AI 不直接提供完整解答程式碼。學習過程以「自行思考 → 提示 → 實作 → 測試與除錯」進行，AI 僅協助觀念理解與提供修改方向。



學習歷程



&#x09;一.建立圖論與 BFS 基礎



&#x09;	首先以「小精靈鬼魂找到玩家」遊戲理解 BFS，將搜尋過程想像成從起點開始，像水波一樣逐層向外擴散。接著學習 queue 的 FIFO 特性，以及 push()、front()、pop() 等操		作，再進一步認識節點、邊、有向圖、無向圖、鄰接表與鄰接矩陣。

&#x09;	

&#x09;	實作方面，練習使用 vector<vector<int>> 建立鄰接表，理解無向邊需要同時記錄 A→B 與 B→A，最後自行完成第一份 C++ BFS 程式。



&#x09;二.深化 BFS 概念

&#x09;	

&#x09;	第二階段將 BFS 延伸至無權圖最短距離。加入距離陣列 d，並進一步使用 d\[x] == -1 同時表示「尚未拜訪」，使距離陣列兼具 visited 與最短距離紀錄的功能。



&#x09;	此階段也分析 BFS 的時間複雜度。使用鄰接表時，每個節點與每條邊只需處理固定次數，因此為 O(V+E)。同時理解 BFS 求得的是最少邊數路徑，適合所有邊成本相同的情況；若		邊具有不同權重，則需進一步使用 Dijkstra 等演算法。



&#x09;三.BFS 能力挑戰



&#x09;	挑戰1－單源 BFS：

&#x09;		

&#x09;		從單一起點出發，計算到所有節點的最短距離，整合鄰接表、queue 與距離陣列等基礎觀念。



&#x09;	挑戰2－多源 BFS：

&#x09;		

&#x09;		將多個起點同時加入 queue，在二維地圖中向外搜尋，計算各位置到最近起點的距離，將 BFS 從一般圖延伸到二維網格。



&#x09;	挑戰3－一次破牆 BFS：



&#x09;		角色需要從 S 到達 T，途中最多可以破壞一面牆。此時只記錄 (r,c) 不足以描述狀態，因此將搜尋狀態擴充為 (r,c,used)，分別表示「尚未破牆」與「已經破牆」。這			使同一位置能保留兩種不同狀態，也是三題中最主要的觀念突破。



&#x09;		若地圖為 H×W，一次破牆最多有 2×H×W 個狀態；若最多可破 K 面牆，則擴充為 K+1 種狀態。



錯誤與修正



&#x09;初期曾誤解 queue.push() 的加入方向、不清楚變數 v 的意義，以及無向邊雙向儲存的原因。後續也曾將 visited 的值誤放入 queue，以及把 d\[x] == -1 的判斷寫反。透過畫圖、測試與	除錯逐步修正，使學習從「看懂程式」進一步轉向理解每個資料結構與設計背後的原因。
