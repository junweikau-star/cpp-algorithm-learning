\# C++ Algorithm Learning Journey



這個 repository 記錄我使用 C++ 學習競技程式設計演算法的過程，包含觀念筆記、練習程式、除錯經驗與學習反思。



\## 學習目標



1\. 建立圖論與動態規劃的基礎

2\. 熟悉 C++ STL 與競程常用資料結構

3\. 練習分析時間與空間複雜度

4\. 透過 GitHub 保存可驗證的學習歷程



\## 專案結構



\- `graph/bfs/`：BFS 程式、筆記與學習反思

\- `graph/dfs/`：DFS 程式、筆記與學習反思

\## 學習方式



每個主題會依序進行：



1\. 理解核心觀念
